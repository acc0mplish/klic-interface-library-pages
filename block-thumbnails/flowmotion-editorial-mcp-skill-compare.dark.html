MCP(모델 연결 규격) vs 스킬(일하는 요령) 비교

좌측 MCP(사내 DB·일정·파일 서버·ERP와 AI를 잇는 USB-C형 공용 연결 규격)와 우측 스킬(엑셀 만들기 등 필요할 때 꺼내 읽는 일하는 요령 설명서 묶음)을 직관적인 듀얼 모션 카드로 비교합니다.

MCP vs 스킬 원본 비교첨부된 레퍼런스 이미지와 동일하게 좌측 MCP 4대 시스템 연결 규격과 우측 스킬(엑셀 만들기 설명서 꺼내 읽기)을 생동감 있는 모션으로 보여줍니다.

MCP (Model Context Protocol, 모델 연결 규격)

손이 닿는 곳을 넓힌다. AI와 다른 프로그램을 잇는 공용 연결 규격. USB-C처럼 한 번 맞춰 두면 여러 AI에서 씁니다.

작동: 시스템마다 ‘MCP 서버’를 두면, AI가 그 서버의 기능 목록(조회·등록 등)을 보고 필요할 때 부름

스킬 (Skill, 일하는 요령)

필요할 때 꺼내 읽기

일하는 요령을 알려 준다. 특정 일을 처리하는 방법을 적어 둔 설명서 묶음. AI가 필요할 때 꺼내 읽고 따라 합니다.
