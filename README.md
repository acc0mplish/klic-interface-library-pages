# KLIC Interface Library GitHub Pages mirror

Static browser assets exported from the private Design-System repository. Worker-backed routes and API transports continue at https://design.klic.co.kr. Rebuild the source first, then sync dist/client to this repository. Also copy the uncompressed HTML from dist/block-thumbnails into block-thumbnails: the Worker client contains these previews as .html.gz, while GitHub Pages iframes request raw .html files. Update thumbnailRevision in github-pages-path-fix.js when the thumbnail payload changes to invalidate cached 404s. Keep the /klic-interface-library-pages/ base path in index.html and _klic-shell.html.
