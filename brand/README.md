# KLIC 2.5D SVG logo kit

Source: original SVG in the user-supplied KL_Logo_Expanded_40_v2_Pure_SVG.zip.

- klic-logo-original.svg: original bytes, unchanged.
- klic-logo-light.svg / klic-logo-dark.svg: transparent 300×300 masters.
- klic-wordmark-light.svg / klic-wordmark-dark.svg: tighter 8 42 286 216 viewBox for website placement; same geometry.
- klic-favicon.svg: light/dark system appearance via SVG CSS.

The original three path d strings and two polyline points strings are preserved. Front coordinates are unchanged. Only auxiliary use elements are offset for a shallow 3-unit depth. Gradients, local masks and fine SVG pattern lines create a satin finish. No perspective rotation, embedded raster, base64, external resources, JavaScript, font dependency or SVG filter. These are editable SVG vectors, not raster exports. Transparent masters contain no background rectangle.

Use the light asset on white/bright surfaces and dark asset on navy/charcoal surfaces. At small sizes the texture is intentionally subtle. Never stretch the logo. Follow the clear-space, scale and application rules in CI-GUIDELINES.md and https://design.klic.co.kr/logo. The original is preferred for small UI; large brand expressions use the 2.5D masters.
