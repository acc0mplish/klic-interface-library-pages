# KLIC corporate logo arrangements

Reference: https://klic.co.kr/logo/
Master: supplied assets/brand/klic-logo-original.svg (unaltered).

Five existing arrangements: symbol, horizontal Korean signature, stacked Korean signature, Korean name, consortium signature. All have color and white versions; symbol/horizontal/stacked also have a white outline version. 5 × 2 + 3 = 13 SVG files.

The symbol paths/points are byte-identical to the supplied master. Only uniform scale and translation are used for placement. Original brand colors remain fixed independently of product color themes.

IMPORTANT: The source website provides the Korean lettering as PNG. The Korean company name in these new SVG arrangements is editable Paperlogy text, not the original lettering outline. The symbol is the original vector. No raster embedding, auto-tracing, base64, scripts or external references are used.

Install fonts/Paperlogy-7-Bold.ttf before editing SVGs offline. Text remains text. The website's inline previews load the same existing font. Applications without the font may substitute another font. The supplied original PNG reference archive is separately available as klic-reference-originals.zip for applications requiring the exact legacy lettering.

Keep the SVG aspect ratio. Scale the entire signature uniformly. White artwork needs a dark backing. Use consortium signatures only for consortium documents. Measure final-size readability on the actual device or printed proof; these files do not assert a national IT/print standard.
