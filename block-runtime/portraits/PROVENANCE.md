# KLIC fictional employee portraits

Generated with OpenAI imagegen (built-in image generation), 2026-10-23.
All subjects are fictional adults; no reference photographs or real-person identities were used.

Four separate 1254 × 1254 PNG atlases each contain 36 studio headshots in a 6 × 6 grid.
The application uses CSS background positioning to show one complete 209 × 209 cell.
No image editing, slicing, or face manipulation was performed.

Prompt direction: photorealistic studio business portraits, mostly Korean and some diverse international adult colleagues aged 26–60, soft light, gray or pale blue backgrounds, restrained navy/white/gray clothing, distinct faces, centered head and shoulders, exactly six rows and six columns without gutters, text, labels, or borders.
Atlas B emphasizes age variation; C includes mature finance/design colleagues; D expands the international cast.

manifest.json records all 129 canonical names, legacy-name aliases, and unique cell assignments.
avatar-inventory.json records the original name / placeholder URL / source-location audit before adaptation.
registry.mjs is the shared browser and runtime lookup; unknown names and nonhuman agents return no portrait.
review.html displays the actual circular CSS crops with their names for visual QA.
