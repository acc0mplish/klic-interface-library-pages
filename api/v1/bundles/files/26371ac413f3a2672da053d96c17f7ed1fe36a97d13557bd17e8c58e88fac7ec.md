## Run

Review source and per-file notices, then run bun install, bun run dev to preview, or bun run build to build. These commands are never executed by the KLIC CLI.

Interactive sample data only. Connect your application's backend separately. Build output is build/. Fonts and portraits are included in public/ and copied by Vite into build/.
