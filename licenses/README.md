# KLIC 출처와 라이선스 안내

이 문서는 사이트에 포함된 파일별 출처·라이선스·보존 고지를 찾는 색인입니다. 사이트 전체나 모든 다운로드에 새 단일 라이선스를 부여하는 문서가 아닙니다. 실제로 사용하는 파일과 의존성의 원문 고지를 함께 확인하세요.

| 대상 | 원문과 보존한 고지 |
| --- | --- |
| 컴포넌트 추가형 | [ReUI·shadcn/ui·Base UI 참고 및 MIT 고지](./component-variants/README.md), 항목별 소스 헤더 |
| AI·상호작용 예제 | [Affect UI Classic MIT 고지](./klic-interaction-kit/MIT.txt), 각 adopted 소스의 고지 |

KLIC은 현재 HTML 데모, 토큰 레지스트리와 참고 소스 전달을 제공합니다. 공개 디자인 API가 특정 파일의 라이선스를 변경하는 것은 아닙니다. 토큰·테마·CLI의 npm 패키지 구현과 레지스트리 발행 상태는 제공 계약에서 구분합니다. 이 패키지가 별도의 React 컴포넌트 API를 제공한다는 뜻은 아닙니다.

공개 KLIC 소스 저장소 주소는 현재 제공 계약에 등록되어 있지 않습니다. 소스는 각 항목의 내보내기와 CLI 묶음에서 확인할 수 있습니다. 외부 참고 저장소는 KLIC 소스 저장소와 구분합니다.
